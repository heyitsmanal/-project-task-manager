# Project Task Manager – Fullstack Mini Project

## 🧠 Description
A full-stack web application that allows users to manage projects and tasks with authentication, progress tracking, and persistent storage.

## 🛠 Tools Used
- Backend: Java 17, Spring Boot, Spring Security, JWT, JPA, Flyway
- Frontend: React, Vite, Bootstrap
- Database: PostgreSQL

## 🚀 How to Run the Backend
```bash
cd backend
mvn spring-boot:run
